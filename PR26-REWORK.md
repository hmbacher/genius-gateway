## 2. What the PR does

It removes type errors reported by `npm run check` in `interface/` without
changing behaviour:

- Modal components `Scan`, `EditNetwork`, `EditUser` extend `ModalProps`;
  `DeviceImportDialog` forwards the modal props to `ProgressDialog`, as
  `PdfReportDialog` already does.
- `Scan`: the interval handle is typed as `ReturnType<typeof setInterval>`.
- `SystemMetrics`, `BatteryMetrics`: chart canvases and scales get non-null
  assertions; a module declaration for `chartjs-adapter-luxon` is added
  (`interface/src/chartjs-adapter-luxon.d.ts`).
- `interface/vite-plugin-littlefs.ts`: the rollup output handling is
  rewritten with guards for array, undefined and non-string filename patterns.
- `interface/src/lib/audio/tuner-worklet.js`: JSDoc types throughout, plus
  ambient declarations for the AudioWorklet globals
  (`interface/src/audio-worklet-globals.d.ts`).
- Small typing fixes in `DateInput`, `menu`, `NTP`, `SystemStatus`.
- The only runtime change: the `catch` block in `TunerProcessor` reads
  `e.message` only for `Error` instances.
